# Rusty Git Client 0.1.0

The first release of Rusty Git Client, a desktop Git client in the spirit of GitKraken for Windows and macOS. It is built with Tauri (Rust) and React, and it uses your own Git installation, so your credentials, SSH setup and config just work.

## Requirements
- **Git** installed and on your `PATH` (the app runs the system `git` for fetch, pull and push).
- Windows needs the WebView2 runtime (included in Windows 11).

## Downloads
- **Windows:** the setup installer (`…_x64-setup.exe`), the MSI, or the standalone `rusty-git-client.exe`.
- **macOS:** the `.dmg`, as built by the release pipeline.
- The builds are **not signed**. Windows SmartScreen shows "unknown publisher" (choose *More info*, then *Run anyway*), and macOS needs right-click, then *Open*, the first time.

## What's in 0.1.0

### Repositories
- Open any folder with the native picker (the repository is found by searching upwards), plus a recent-repositories list.
- Shows the current branch, a detached HEAD, and repositories with no commits yet.
- Live reload: the graph, branch label and file lists update by themselves when the repository changes, including from the terminal or another tool.

### Commit graph
- All branches, remote branches and tags, with a coloured lane layout, ref chips, and columns for message, author, date and hash.
- Fast scrolling through long histories, loaded in pages.
- A dashed row on top shows your uncommitted changes. Click it to return to the staging panel.
- Select a commit with the mouse or the ↑/↓ keys.

### Committing
- Staged and unstaged file lists with status badges. Stage or unstage single files or everything.
- Commit message box. Commit with the button or `Ctrl`/`Cmd` + `Enter`.
- **Amend previous commit** switch, with a warning when the commit is already pushed.
- Finishes in-progress merges.
- Right-click a file for **Stage**, **Discard changes** (or delete or restore the file) and **Stash**, or **Unstage** and **Stash** for staged files.

### Diffs and hunks
- Click a changed file, in a commit or in the staging panel, for a diff with line numbers and a **Full file** switch.
- Every run of changed lines is a hunk with **Stage hunk**, **Discard hunk** and **Unstage hunk** buttons. CRLF files and a missing final newline are preserved.
- ↑/↓ move between the changed files while a diff is open.
- Commit details show message, author, date, parents and changed files, including renames and merge commits.

### Stashes
- **Stash…** moves all uncommitted changes, including untracked files, into a stash, optionally with a message.
- Stashes appear in the graph and in a left-panel list. Click one to see its files and diffs.
- **Pop** (button or right-click) puts the changes back, and is undone cleanly if it would conflict. **Delete stash** is in the right-click menu.

### Rewriting history
- **Rename commit** rewrites a commit's message and rebuilds the commits after it.
- **Drop commit** removes a commit; if a later commit depends on it, nothing is changed.
- **Reset to this commit** (soft, mixed or hard) from a submenu, each with a confirmation that spells out the consequences.
- **Interactive rebase** is a full screen listing the commits after the one you chose:
  - actions per commit: **pick**, **reword** (popup editor), **squash** into the commit before it, and **drop**;
  - reorder commits with **Move commit up/down**, from the right-click menu or `Ctrl`/`Cmd` + `↑`/`↓`;
  - click a commit to see its files and open their diffs;
  - conflicts cancel the whole rebase with nothing changed, and the footer warns about pushed history.

### Branches and remotes
- Local branches with ahead/behind counts. Double-click to check out, create new branches (toolbar button or the **⋯** menu), rename and delete.
- Several remotes: add, edit the URL, remove, and choose which one new branches are pushed to. Rename and delete remote branches.
- A filter field narrows local branches, remote branches and stashes at once, and the three sections always keep their headlines visible.

### Fetch, pull and push
- Fetch, Pull and Push buttons run your system Git, with `↓n` / `↑n` counts. Pull is fast-forward only.
- When branches have diverged, a dialog offers **Merge** (the default) or **Rebase**. Conflicts cancel the pull and leave your repository exactly as it was.
- **Pull (merge)** and **Pull (rebase)** are in the Pull button's menu.
- **Force push** (with lease) is in the Push button's menu, behind a confirmation.
- **Auto-fetch** is on by default every 3 minutes, only while the window is focused. It backs off when you're offline and pauses when credentials are needed. A yellow ⚠ beside a remote shows when a fetch fails.

### Terminal and polish
- A built-in terminal (PowerShell on Windows, your login shell on macOS) opens in the repository folder with `Ctrl` + `` ` ``.
- A dark theme throughout, resizable side panels, and themed scrollbars.
- The browser's native right-click menu is switched off, so right-clicks only open the app's own menus.

## Known limitations
- No conflict-resolution screen yet: conflicting pulls and rebases are cancelled, and you resolve them in the terminal.
- Not built yet: tags in the sidebar, checking out remote branches, applying a stash without removing it, single-line staging, syntax highlighting and a side-by-side diff.
- Dropping, moving or resetting commits needs a clean working directory.
- Only English, and only the standard Tauri placeholder icons.
